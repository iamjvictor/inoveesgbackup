# InoveESG

Projeto organizado em backend, frontend e materiais compartilhados. Este repositório de backup acompanha também a documentação, os modelos de diagnóstico e os arquivos da raiz.

## Estrutura

- `backend/`: API, regras de negócio e migrações.
- `frontend/`: aplicação web.
- `docs/`: documentação do produto e do projeto.
- `modelos_diagnostico/`: modelos usados nos diagnósticos.
- Arquivos na raiz: documentação de trabalho e configuração compartilhada.

## Ambiente local

Os exemplos de variáveis ficam em cada aplicação. Copie-os e preencha as credenciais localmente:

```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env.local
```

Os arquivos `.env` com valores locais não devem ser commitados.
